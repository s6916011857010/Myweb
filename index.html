3. ผลงานบทความวิจัย - ผลงานทางวิชาการ

การศึกษาวิจัยเชิงลึกและการทดลองประเมินผลการพยากรณ์ราคาด้วยเครื่องมือเหมืองข้อมูล WEKA

ตีพิมพ์ลงวารสารมหาวิทยาลัย Peer-Reviewed Journal WEKA Data Mining Cross-Validation: 10-Fold

การพยากรณ์ราคาด้วยการเรียนรู้ของเครื่องจักรด้วยโปรแกรมเวก้า

ตีพิมพ์ใน: วารสารมหาวิทยาลัยเทคโนโลยีพระจอมเกล้าพระนครเหนือ | หมวดหมู่วิทยาการคอมพิวเตอร์และปัญญาประดิษฐ์

บทความวิจัยนี้นำเสนอระเบียบวิธีการประยุกต์ใช้อัลกอริทึมการเรียนรู้ของเครื่องจักร (Machine Learning Algorithms) บนโปรแกรม Waikato Environment for Knowledge Analysis (WEKA) เพื่อวิเคราะห์และพยากรณ์แนวโน้มราคา จากการทดลองเปรียบเทียบโมเดลต่างๆ เช่น Random Forest, Support Vector Machines (SMO), Multilayer Perceptron และ Linear Regression พบว่าอัลกอริทึม Random Forest ให้ค่าความถูกต้องสูงสุดถึง 94.2% และมีค่าความคลาดเคลื่อนสมบูรณ์เฉลี่ย (MAE) ต่ำที่สุดเพียง 0.118

การพยากรณ์ราคาด้วยการเรียนรู้ของเครื่องจักรด้วยโปรแกรมเวก้า (Price Forecasting using Machine Learning with WEKA)

บทคัดย่อ (Abstract):

งานวิจัยนี้มุ่งเน้นการศึกษาความสามารถในการพยากรณ์ราคาของอัลกอริทึมการเรียนรู้ของเครื่อง (Machine Learning Algorithms) ที่รันบนแพลตฟอร์ม WEKA โดยทำการเปรียบเทียบโมเดลในตระกูล Decision Trees, Support Vector Machines, Neural Networks และ Regression เพื่อค้นหาโมเดลที่มีความแม่นยำสูงสุดและมีค่าความคลาดเคลื่อนต่ำที่สุดสำหรับนำไปประยุกต์ใช้ในการตัดสินใจเชิงธุรกิจ

ระเบียบวิธีวิจัยและการประเมินผล (Methodology):
  • การเตรียมข้อมูล (Data Pre-processing): การกรอง Missing values และการทำ Normalization บน WEKA
  • การทดสอบ (Validation): 10-Fold Cross-Validation เพื่อป้องกันการเกิด Overfitting
  • ดัชนีชี้วัด (Metrics): Correlation Coefficient (%), Mean Absolute Error (MAE), Root Mean Squared Error (RMSE)
ข้อสรุปเด่น: Random Forest ให้ผลลัพธ์ดีที่สุดที่ค่า Correlation 94.2% และ MAE 0.118
